03

内置技能 · 8 个

技能目录位于 ~/.manus/skills（软链接为 ~/skills），遵循 Agent Skills 规范，每个技能是一个含 SKILL.md 的目录，按需加载完整指令。

automation-and-scheduling 含 references

自动化与调度决策指南：在 Manus 定时任务、WebDev Cron / Heartbeat、预留托管、持久沙箱之间做架构选型。核心原则——禁止用定时任务做分钟级轮询（每次运行都会拉起完整会话，昂贵且架构错误），高频轮询应交给 WebDev 常驻进程。

clear-communication

面向用户的表达规范：默认直接在对话中给出实质答案而非甩文件；文档仅用于用户明确要求或需要长期保存的深度研究；配 1–2 个简洁的可视化，兼顾手机阅读体验。

cue-product

Cue 应用产品知识库：覆盖 iOS / Android / Mac / Windows 四大平台（无浏览器版），Agents、群聊、Scan & Create、Computers、订阅计费等功能的入口与操作路径说明。

data-api 含 scripts

Manus 数据 API 网关：一次调用即可获取 X/Twitter、LinkedIn、YouTube、TikTok/Instagram/Reddit 内容，金融市场行情、SEC 文件、Crunchbase、世界银行指标、Google Trends、App Store 排名，以及文生 3D 模型。

gws-best-practices

Google Workspace CLI（gws）最佳实践：支持 Drive / Docs / Sheets / Slides 四类服务。新建文档须本地用 python-docx 生成 .docx 再上传；编辑既有文档只能用 batchUpdate 以保留批注。Gmail、Calendar 等不可用。

manus-config

五大配置域 CLI：Agent 档案管理（agents）、Agent 群聊（group）、连接器（connector ensure）、项目级配置（config load/save）、定时任务（schedule，单任务单计划）。

manus-touchpoint 外部触达

代表用户发送邮件、短信或发起 AI 外呼，并查询历史记录（含附件、转录文本、录音）。前提是会话中提供已启用的 TouchPoint 联系人。

skill-creator 含 scripts+references

技能创作指南：技能是扩展 Manus 的模块化知识包（工作流、工具集成、领域知识、资源文件）。强调"简洁至上"、描述决定加载时机、修改前必须先读本技能走更新流程。
