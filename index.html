档案方法论

每一份入库报告都遵循同一套取证流程，保证横向可比。

① 系统底座

OS / 内核 / CPU / 内存 / 磁盘 / GPU，一律实机采样，拒绝"约"和"大概"。

② 能力矩阵

③ 边界与代价

网络出口、安全模型、持久化语义、资源配额——沙盒的边界即设计。
