01

这个项目是什么

GitHub Stars 是 GitHub 官方的社区荣誉项目。它不奖励「代码写得多的人」，而表彰那些 inspire、educate、influence 社区的人——这正是理解这份名单的钥匙。

★ 评选机制

任何人都可以提名他人（不能自荐），提名需附上社区影响力的具体事例；GitHub 团队做预审与评审，通过后在社交媒体公布。看的是贡献的质与量，不只看 commit 数。

★ 什么算贡献

官方列出的例子包括：开源项目、博客、视频、播客、线下活动、用户组、演讲。写教程、做视频、组织社区、维护文档——这些都被正式承认为贡献。

★ 任期与续评

任期为一年（获邀当年 1 月 31 日至次年 1 月 30 日），每年重新评审续期。名单是活的——这 92 位是 2026-10 时点的现任 Stars。

★ Stars 得到什么

新功能内测与反馈通道、与 GitHub 团队的直接交流、进阶学习资源、活动与演讲邀约、专属周边，以及一座刻着自己名字的实体星星奖杯。

💡 关键洞察：这份名单里近半数是教育家、布道者与社区组织者，而非传统意义上的「大神程序员」。GitHub 用这个项目传递了一个明确信号——让更多人学会、让社区更好，本身就是最高级的贡献。这也是本页第 ④ 章存在的原因。

04

可以从他们身上学到什么

92 份档案读完，真正值得带走的不是名单，而是七条可复制的路径。

01

影响力 ≠ 代码量

名单里近半数是教育家、布道者与社区组织者。GitHub 官方的评选标准是 inspire / educate / influence——写教程、做视频、组织活动、维护文档，同样是「贡献」。先把「我要对社区有用」放在「我要写很多代码」前面。

02

把重复劳动产品化

antfu 的每个工具都始于自己的痛点。你每天手动做的事，就是下一个工具的雏形。工具链工匠的起点不是宏大叙事，是「受够了」。

03

选一个足够重要的问题，做长期主义者

bagder 维护 curl 二十多年，foosel 众筹做 OctoPrint 十年。时间的复利只奖励不换赛道的人——选底层、选重要、选你愿意做二十年的。

04

做「规则层」的贡献

ESLint、Cobra、Testing Library——定义别人怎么写代码的工具，影响力是应用层的指数倍。往下走一层，杠杆大十倍。

05

在范式转移期做翻译者

chiphuyen 在 MLOps/LLMOps 爆发期做体系化输出，simonw 在 LLM 时代持续写作。窗口期 × 写作能力 = 巨大杠杆；写清楚一件事的人，会被记住。

06

母语是蓝海

西语（mouredev / midudev）、中文（HelloGitHub）、韩语、葡语——非英语高质量技术内容永远稀缺。用母语服务母语者，竞争少、需求大、粘性强。

07

可持续性是架构问题

foosel 的众筹、antfu 的赞助转发倡议——先解决「自己能一直做下去」，再谈改变世界。开源的敌人不是技术难度，是 burnout。
